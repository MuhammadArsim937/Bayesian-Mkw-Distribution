# Bayesian Inference for the New Modified Kumaraswamy (Mkw) Distribution

Bayesian Estimation for the New Modified Kumaraswamy (Mkw) Distribution under
Uncensored and Progressively Censored data using different Loss Functions.

Thesis by Muhammad Arsim, MPhil, Quiad i Azam University Islamabad, 2026.
Supervisor: Dr. Maryam Asim

## Abstract

The New Modified Kumaraswamy (Mkw) distribution, introduced as a flexible
extension of the Modified Kumaraswamy distribution, has gained considerable
attention for modeling bounded random variables on the unit interval (0, 1).
Due to its enhanced flexibility, the NMKW distribution is particularly suitable
for applications involving proportions, rates, reliability measures, and
lifetime data. Motivated by these properties, this study develops a
comprehensive Bayesian inference framework for the NMKW distribution under both
uncensored and progressively censored data. Bayesian parameter estimation is
carried out under three practically relevant scenarios: (i) only the shape
parameter alpha unknown, (ii) only the shape parameter beta unknown, and
(iii) both parameters unknown. To obtain robust Bayesian estimators, several
symmetric and asymmetric loss functions are considered, including the Squared
Error Loss (SEL), Absolute Error Loss (AEL), Quadratic Loss Function (QLF),
Entropy Loss Function (ELF), and LINEX Loss Function. The Maximum Likelihood
Estimator (MLE) is also included as a classical benchmark. Estimator
performance is evaluated using the Bayes risk criterion, which serves as a
fundamental measure of efficiency in Bayesian decision theory. The proposed
methodology is applied to two real datasets and further validated through an
extensive Monte Carlo simulation study based on 10,000 replications. The
results reveal consistent performance patterns across different prior
distributions, namely Uniform, Jeffreys', and Gamma priors, as well as across
varying levels of censoring. For small parameter values, the LINEX loss
function frequently yields the minimum Posterior risk, whereas for moderate to large
parameter values, the Entropy Loss Function consistently outperforms all
competing loss functions across all estimation scenarios. The superiority of ELF
remains stable under progressive censoring and joint parameter estimation.
Overall, the findings demonstrate that asymmetric loss functions provide more
efficient Bayesian estimators than symmetric loss functions for the Mkw
distribution. Among all loss functions considered, the Entropy Loss Function
emerges as the most efficient and robust choice in terms of minimum posterior risk.
These results highlight the importance of loss function selection in Bayesian
analysis and confirm the practical effectiveness of the proposed Bayesian
framework for modeling bounded data on the unit interval (0, 1).

## Keywords
Bayesian estimation, Mkw distribution, loss functions, Posterior risk,
progressive censoring, Monte Carlo simulation
